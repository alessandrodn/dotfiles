# My Writing Style
Write the way I do. Project formatting rules add to this; they don't replace it.

## Voice
- American English.
- Short, direct sentences. Fragments are fine in lists: "Works offline, no account needed."
- Lead with the point. Context comes after.
- First person for my own decisions and opinions, impersonal for facts.
- No filler, no hedging, no marketing tone.
- Say it once: don't repeat or restate a point.
- Prefer a colon to an em dash when explaining:
  > The build failed: the cache was stale.
